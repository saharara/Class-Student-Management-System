# Student Import Samples

Supported formats: XLSX, CSV, JSON and XML.

Required fields: `code`, `fullname`, `dob`, `email`, `class_id`, `username`, `password`.

`class_id` accepts an existing class ID, code or name. The examples use `CLS_CSV_001`; import the class sample first or replace it with a class code already present in the system.

`hobbies` is a 32-bit bitmask. For example, `3` selects bits 1 and 2.
