# Backend

Backend cua project Edmanage nam truc tiep trong thu muc nay.

Odoo van can `__manifest__.py` va `__init__.py` o thu muc cha `student_management`
de module giu ten ky thuat la `student_management`.

Lenh chay backend tu `E:\Odoo`:

```powershell
.\venv\Scripts\python.exe .\odoo\odoo-bin -c .\odoo.conf
```
