# Class and Student Management System

A web-based application for managing classes and students, built to practice **Business Analysis** and **Full-stack Development** using **Odoo 18** and **React**.

## Features

* Manage students and classes (CRUD)
* Assign students to classes
* Import and export data
* RESTful API integration
* Data validation and business rules
* Responsive user interface

## Business Analysis

* Requirement analysis
* Use Case Specification
* UML Diagrams (Use Case, Activity, Class, Sequence)
* Wireframe design
* RESTful API specification
* Business rules and data constraints
* System documentation

## Wireframe: https://www.figma.com/design/JjFFglYi9O8JLLOsZnQ5JD/Training?node-id=121-4861&t=3x0O3gfJmWLOwKnl-1

## Tech Stack

**Backend**

* Odoo 18
* Python
* PostgreSQL

**Frontend**

* React
* Ant Design
* Redux
* Axios

## Run the Project

### Backend

```bash
python odoo-bin -c odoo.conf
```

### Frontend

```bash
cd frontend
npm install
npm start
```
